# Northwind dataset (CSV)

Zet hier de CSV-files van de Northwind dataset, bv. `customers.csv`, `orders.csv`, `products.csv`, `suppliers.csv`, `employees.csv`, ...

Download via de Neo4j import-tutorial (https://neo4j.com/developer/import/) of upload ze rechtstreeks in de Neo4j Aura webinterface. In Cypher kan je ze dan laden met `LOAD CSV WITH HEADERS FROM 'file:///customers.csv' AS row ...` (bij een lokale/standalone Neo4j) of via de webinterface-upload bij Aura.
